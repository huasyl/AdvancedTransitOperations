# Advanced Transit Operations

Source code for the Cities: Skylines II mod Advanced Transit Operations.

## Structure

- C# mod runtime: `Dispatch/`, `Bypass/`, `TrackModel/`, `TrackProjection/`, `PassengerFlow/`, `Broadcasting/`, and related directories.
- Game UI module: `rapidtransit-ui-module/src/`.
- Dispatch workbench frontend: `workbench-app/src/`.
- Localization files: `Locales/`.
- Third-party notices: `THIRD_PARTY_NOTICES.txt`.

License information is provided in `LICENSE` and `THIRD_PARTY_NOTICES.txt`.
